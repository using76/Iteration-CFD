# cases/pipe_tet_L1 — Gate 116-P's pipe (SPEC-LIT 116.17, TET-14)

A straight pipe, R 0.5 m and L 12 m along +x, laminar and steady at
U_in = 1 m/s uniform, nu = 0.01 m^2/s — Re = 100 — on tetrahedra with three
prism layers on the wall. This is SPEC-LIT 116.17's L1 rig and Gate 116-P of
`ofgpu-validate`'s: the fitted dp/dx over x in [7, 11] m, past the entrance
length (about 5.7 diameters at Re 100), against Hagen-Poiseuille
(116.27) at Q = U_in A_inlet, bar 2 %.

The dict files here are the tracked case; the `constant/polyMesh` the
automesher writes and the solver's time directories are GENERATED, not kept —
a fresh clone regenerates them with the recipe below.

## The recipe (from the repository root)

Make the geometry and mesh it (the pipe's STL is generated by the example's
script; `pipe_tet.json` carries the mesh's H 0.1, B 2.5, layers n 3 /
t1 0.002 / growth 1.2, and writes this case's polyMesh):

    cd tools/automesher/examples && python make_pipe_stl.py && ..\..\..\rust\target\release\ofgpu-automesher pipe_tet.json

Solve it (writes the fields of the last check into `cases/pipe_tet_L1/1500`):

    rust\target\release\ofgpu-lowmach cases\pipe_tet_L1 -iters 1500 -check 250

Record the numbers Gate 116-P replays (build, commit and wall time in
`OFGPU_PIPE_TET_META`, comma-separated; the test prints a `PipeTetRecord`
literal to paste into `rust/src/bin/validate_gates/pipe_tet.rs`):

    cd rust
    OFGPU_PIPE_TET_CASE=../cases/pipe_tet_L1 OFGPU_PIPE_TET_META="f64,<commit>,<seconds>" \
      cargo test --release --bin ofgpu-validate record_pipe_tet -- --ignored --nocapture
