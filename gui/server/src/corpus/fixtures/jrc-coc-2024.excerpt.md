5 Cooling
This section covers the cooling of the data centre and the air flow that carries it.
Each practice carries an Expected Value of 1 to 5 and an applicability column.

5.1 Air Flow Management and Design
Computational Fluid Dynamics (CFD) can help to achieve an optimal airflow design if
used during the early planning stages prior to construction or room fit-out.
Air management actions do not result in an energy saving themselves; they are
enablers which need to be tackled before temperature set points can be raised or
airflow volumes reduced.

5.1.1 Design - hot / cold aisle separation. Expected value 5.
Equipment is installed so that cold intake air and hot exhaust air are separated.

5.1.2 Design - containment design concepts. Expected value 5.
Containment prevents the cold supply air and the hot exhaust air from mixing.

5.1.4 Design - blanking plates. Expected value 4.
Blanking plates are installed wherever there is no equipment in a cabinet.

5.3 Temperature and Humidity Settings
Set points are the lever that air flow management exists to make usable.

5.3.1 Review and if possible raise the target IT equipment intake air temperature.
Expected value 4. Data Centres should be designed and operated at their highest
efficiency to deliver intake air to the IT equipment within the ASHRAE Class A2
allowable range. Operations in this range enable energy savings by reducing or
eliminating overcooling.

5.3.2 Review and if possible reduce the lower humidity set point.
Expected value 4. Reducing the lower humidity set point within the ASHRAE Class A2
range cuts humidification demand.
